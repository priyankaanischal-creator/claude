# 10 — EDITORIAL HELP GUIDE (Knowledge File)

After the script is finished, Claude produces ONE "Editorial Help" package so the
video is ready to publish. It is generated post-script (it needs the finished
story). It contains six sections.

---

## WHAT CLAUDE OUTPUTS (the Editorial Help file)

### 1. TITLE OPTIONS
7–10 options across ≥3 of the formats in file 06; honesty + variety rules apply;
none clashing with the previous episode's format (check Ledger). Human picks one.

### 2. DESCRIPTION
```
[Hook — 2–3 sentences teasing the case, no spoilers.]

🕯️ Tonight, from Watson's dispatch box: [one-line premise].

📖 Chapters:
00:00  Cold Open
[mm:ss]  [Chapter title]
[mm:ss]  [Chapter title]
...        (timestamps = YouTube chapters; fill after final edit)
[mm:ss]  The Solution
[mm:ss]  A word from the Curator (outro)

🎙️ About this video:
An original Sherlock Holmes story, written and produced by [Channel Name].
The narration uses an AI voice; the story, writing, and editing are our own.

⚖️ Disclaimer:
Sherlock Holmes and Dr. John Watson are public-domain characters. This is an
original story, not affiliated with any official adaptation, and uses no
copyrighted text, audio, or images. All material complies with YouTube's
copyright and content policies.

#SherlockHolmes #DetectiveStory #Audiobook #MysteryStory
```
> Claude fills chapter titles; YOU add the final mm:ss timestamps after editing.
> 3–4 relevant hashtags only (not a wall of tags).

### 3. VIDEO TAGS (8–10)
Example set (Claude tailors to the episode):
`sherlock holmes, sherlock holmes audiobook, detective story, victorian mystery,
mystery story, whodunit, crime story, bedtime mystery, sherlock holmes new story,
audio drama`

### 4. QUIZZES (2 — for YouTube's quiz feature)
Canon-accurate Sherlock trivia (general, not episode spoilers). Each = a question,
4 options, the correct answer marked. **Fact-check each before publishing.**
```
QUIZ 1
Q: Which instrument did Sherlock Holmes play?
A) Piano   B) Violin ✓   C) Flute   D) Cello

QUIZ 2
Q: What was the house number of Holmes and Watson's Baker Street lodgings?
A) 221B ✓   B) 21B   C) 121   D) 222B
```

### 5. THUMBNAIL CONCEPT
From file 06:
```
Hero object: [one crucial object from the case]
Lighting/mood: [e.g. single warm lamp, deep shadow, cold blue rim-light]
Overlay text (optional, 2–4 words): "..."  (or none)
Brand element: [consistent corner emblem / dispatch-box label / fixed font]
```

### 6. SFX CUE SHEET
The checklist from file 11 (≤30 cues), mapped to the fixed SFX library, plus a
note on any sound to add. (The SFX-tagged script is delivered alongside.)

---

## OUTRO TALKING-POINTS (delivered with this package)
The outro is spoken by YOU on camera, in your own words — so Claude gives
**3–5 short, story-specific talking points**, NOT a script to read verbatim
(reading word-for-word looks stiff). Rotate the **angle** each episode (log it in
the Ledger) so endings never feel templated:

| Angle | Example talking point |
|-------|-----------------------|
| Fair-play callback | "Did you catch the [clue] before Holmes did? Tell me below." |
| Character | "What did you make of [original character] this time?" |
| Audience choice | "Which case from the box should I open next?" |
| Theory invite | "One thread I left loose: [X]. What's your theory?" |
| Behind-the-scenes | "This one was a devil to plot — here's why…" |
| Reply to a comment | (answer a top comment from the last video) |
| Real-history tease | "The real history that inspired this: [non-gory fact]." |

Claude tailors these to the actual story (the real clue, the real twist) so they
sound genuine.
