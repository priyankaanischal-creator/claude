# 02 — STORY MATRIX & CATEGORIES (Knowledge File)

This is the **macro variety engine**. Every episode is a unique combination of
independent "dials." With this many dials, repetition becomes mathematically
near-impossible — IF you rotate them and respect the cooldowns (see file 04/08).

> Mental model: a DJ mixer. Each dial is a knob. You pick a different setting on
> each knob per episode. The combination is the episode's DNA.

---

## THE 14 CASE CATEGORIES (all canon-grounded)

Each is proven by real Arthur Conan Doyle stories, so they fit Holmes perfectly.

| # | Category | Canon proof |
|---|----------|-------------|
| 1 | Blackmail / Scandal / Reputation control | *A Scandal in Bohemia, Charles Augustus Milverton* |
| 2 | Theft / Robbery / Recover the object | *The Beryl Coronet, The Blue Carbuncle, The Mazarin Stone* |
| 3 | Fraud / Imposture / Identity tricks / Domestic deception | *A Case of Identity, The Red-Headed League, The Man with the Twisted Lip* |
| 4 | Coded message / Symbol / Cipher / Pattern | *The Dancing Men, The Musgrave Ritual, The Gloria Scott* |
| 5 | Missing person / Disappearance / Kidnapping / Lost lady | *Lady Frances Carfax, The Priory School* |
| 6 | Murder / Suspicious death / Violent crime | *The Boscombe Valley Mystery, The Speckled Band* |
| 7 | "Odd phenomenon" / Supernatural-frame, rational core | *The Hound of the Baskervilles, The Sussex Vampire, The Devil's Foot* |
| 8 | State secrets / Espionage / National security | *The Naval Treaty, The Bruce-Partington Plans, His Last Bow* |
| 9 | Institutional / Professional mystery (law, academia) | *The Three Students, The Missing Three-Quarter* |
| 10 | Legacy / Ancient household secret / Ritual / Old family code | *The Musgrave Ritual, The Five Orange Pips* |
| 11 | Relationship / Marriage / Social problem (non-murder) | *The Yellow Face, The Solitary Cyclist, The Noble Bachelor* |
| 12 | Threat letter / Warning / Countdown (menace-driven) | *The Five Orange Pips, The Red Circle* |
| 13 | Workplace / Trade / Occupational hazard (strange job) | *The Engineer's Thumb, The Copper Beeches* |
| 14 | Mycroft / Interpreter / Network-intelligence | *The Greek Interpreter, The Bruce-Partington Plans* |

**Frequency note:** #1–#7 are rich and can recur often (respecting cooldown).
#9 and #14 are "thin" in canon — use them rarely, which makes them feel special.

## THE DIALS (choose ONE value per dial, per episode)

For each new episode, fill these. Check the Ledger (file 08) so nothing repeats
inside its cooldown window.

1. **FORMAT** — from file 03 (Standard / Dispatch Box / Casebook / Journal / etc.)
2. **CASE CATEGORY** — 1 of the 14 above.
3. **MYSTERY STRUCTURE** — Whodunit / Howdunit (inverted) / Whydunit /
   Locked-room / Alibi-breaker / Dying-message / No-body / Least-likely-suspect /
   "Detective is wrong."
4. **SETTING** — pick a *distinct* world (see Asset Bank file 07). The setting
   should drive all sensory detail.
5. **VICTIM / CLIENT PROFILE** — who they are and why we care.
6. **THE CENTRAL LIE** — the one false thing everyone believes (the story's core).
7. **REAL MOTIVE** — go beyond money/jealousy: shame, protecting someone, mercy,
   mistaken identity, decades-old revenge, accident cover-up, ideology, a secret.
8. **METHOD / WEAPON** — from Asset Bank; never a recent repeat.
9. **MISDIRECTION MECHANISM** — false suspect / false timeline / false motive /
   false victim-identity / tampered evidence.
10. **SOLUTION "TRICK"** — twin / disguise / timing / hidden passage /
    suicide-staged-as-murder / unreliable witness / two overlapping crimes /
    "no crime occurred."
11. **RED HERRING TYPE** — physical / psychological / false alibi / planted.
12. **ENDING TONE** — justice served / bittersweet / killer escapes / Holmes lets
    them go / tragic.
13. **SENSORY LENS** (anti-repetition booster) — solve primarily via ONE sense:
    sound / smell / touch / sight-detail. Forces fresh micro-detail each time.
14. **ASSIGNED PROPS** — pick 3–5 concrete objects from the Asset Bank to anchor
    the case. Holmes must NOT invent atmosphere beyond these.

## WHY THIS KILLS REPETITION (the math)

Even using only 5 main dials with ~8 options each:
`8 × 8 × 8 × 8 × 8 = 32,768` unique skeletons — before settings, props, tones.
At 1–3 videos/week you will never exhaust the macro space. The real battle is
*micro* repetition, handled in file 04.

---

## CONSTRAINT-FIRST WRITING (use it)

Don't start from "a Sherlock murder." Start from a **specific assigned constraint**
and build outward. Example: "The only clue is a half-burnt 1887 theatre ticket
for *The Mikado* that smells faintly of kerosene — build the whole deduction
around this." Constraint-first writing produces more original plots AND blocks
the AI's default tropes at the source.
