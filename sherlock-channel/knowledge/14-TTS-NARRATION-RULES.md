# 14 — TTS / AI-NARRATION RULES (Knowledge File)

The script is read by an **AI voice**. Sherlock listeners hang on every word, so
a single mispronunciation or a clumsy pause breaks the spell. Write every script
so the AI narrator sounds clean, natural, and elegant — like Conan Doyle read by
a fine human narrator. These rules are MANDATORY for all narration text.

> Apply these while drafting chapters AND check them in the polish pass.

---

## 1. PUNCTUATION = PACING (the most important rule)
The AI voice pauses and breathes on punctuation. Use it deliberately.
- **Comma** = short breath. Use commas to shape the rhythm of a sentence.
- **Full stop** = full stop. Prefer **shorter sentences** for narration clarity.
- **Em dash (—)** = a sharp break or interruption in dialogue. Good for tension.
- **Ellipsis (…)** = a trailing, hesitant pause. Use sparingly, for effect.
- **Paragraph break** = a longer beat. Break paragraphs often (audio needs air).
- Avoid semicolons in narration — many TTS engines rush them. Use a full stop.
- Avoid long sentences with many sub-clauses; they make the AI run out of breath
  and sound flat. Split them.

## 2. WORDS THE AI OFTEN MISPRONOUNCES — write around them
- **Abbreviations:** write them out. "Doctor" not "Dr." in narration; "Mister"
  / "Mistress" rather than relying on "Mr./Mrs." where a misread would jar.
  ("St." → "Saint" or "Street" depending on meaning. "Co." → "Company".)
- **Numbers & years:** spell out for natural reading. "eighteen eighty-nine"
  not "1889"; "half past nine" not "9:30"; "the twenty-third" not "23rd".
- **Roman numerals:** never use them in narration ("the Third", not "III").
- **Money:** "three pounds ten" / "a half-crown" — write as spoken, not "£3 10s".
- **Ampersand (&), %, #, etc.:** never in narration — write "and", "per cent".
- **Latin/French/archaic terms:** if used, ensure the spelling guides the sound,
  or replace with a plain English equivalent.

## 3. NAMES & UNUSUAL VOCABULARY
- Choose character/place names that are **easy to pronounce on sight**. Avoid
  exotic spellings the AI will fumble.
- If a distinctive name MUST be used, add a one-time pronunciation note in
  brackets for the editor (NOT to be voiced), e.g. `Featherstonehaugh
  [pron: FAN-shaw]`, and prefer a respelling in the spoken text if possible.
- Avoid heavy phonetic dialect spelling ("'ere, guv, wotcher") — the AI garbles
  it. Convey class through **word choice and rhythm**, not broken spelling
  (see file 04 / craft rules). Keep working-class speech clear but plainer.

## 4. CLARITY HABITS
- One idea per sentence in tense moments.
- Avoid tongue-twisting consonant clusters and unintended rhymes.
- Avoid homographs where the wrong reading is likely ("lead", "tear", "wound",
  "bow", "row") — rephrase if the AI might pick the wrong sense.
- Read-aloud test: if a human would stumble, the AI will too. Rewrite it.

## 5. DIALOGUE TAGS & DELIVERY
- Keep tags simple ("he said", "she answered"). The voice conveys emotion; don't
  overload with adverbs.
- For emphasis, *rephrase* rather than rely on italics (TTS may ignore them).
- Mark speaker changes with clear new paragraphs so the listener never loses who
  is speaking.

## 6. SFX / EDITOR TAGS ARE NOT VOICED
Any bracketed tag like `[SFX: door_heavy_open]` or a `[pron: …]` note is an
editor instruction and must be on its **own line**, never inside a spoken
sentence, so it is never read aloud by the AI. (See file 11.)

---

## QUICK CHECK (run during the polish pass)
- [ ] No raw numerals, years, abbreviations, or symbols in spoken lines
- [ ] No semicolons; sentences short enough to read in one breath
- [ ] No phonetic-dialect spelling; class shown through word choice
- [ ] Hard names given a [pron: …] note or respelled
- [ ] All bracketed tags on their own lines (won't be voiced)
- [ ] Reads aloud smoothly, elegantly, with Doyle-era dignity
