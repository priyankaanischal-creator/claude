# 01 — PROMPT MASTER TEMPLATE (Trump Project)

Exact skeletons Claude must follow when writing the image prompt. Fill every `[ ]`
with vivid, specific detail. **Never leave a blank.** Every skeleton already
contains the **CROP-SAFE 4:5 block** + a small **"AI ART" tag** — keep them and
only swap the `[colour]`/`[detail]` parts.

Three skeletons: **2-character**, **3-character**, **4-character (2×2 grid)**.

---

## ⭐ THE CROP-SAFE 4:5 BLOCK (goes at the TOP of EVERY prompt)
```
Create a vertical portrait image. Design ALL content inside a centred 4:5 safe
zone (final crop = 1080 x 1350 px, ratio 4:5). The source canvas may render
TALLER than 4:5, so the TOP and BOTTOM strips WILL be cropped off — therefore:
- TOP ~15% = a solid [BAND COLOUR] band with NOTHING important in it.
- BOTTOM ~15% = a solid [BAND COLOUR] band with NOTHING important in it.
- Put the headline BELOW the top band; put all name labels ABOVE the bottom band.
- Keep every figure's head and feet/body well inside the central zone.
- The left and right edges are safe (only top/bottom get cropped).
Make the top/bottom band colour match the design so a crop looks seamless.
```
> Set `[BAND COLOUR]` to match the chosen header/theme (navy theme → navy bands).

## ▶ SINGLE-PERSON TIMELINE NOTE
If the user gives ONE name (e.g. "Trump"), build a 3 or 4-panel **timeline** of
that person across DIFFERENT eras (e.g. businessman → campaign → president), using
the 3- or 4-character skeleton with the same face but different era/outfit/scene
per panel. Label each panel by era ("THE 80s", "THE CAMPAIGN", etc.).

## ▶ COUPLE-VS-COUPLE NOTE
If a panel holds a couple (e.g. "Donald & Melania" vs "Ivanka & Jared"), use the
**2-character skeleton** but each panel shows TWO people standing close together.
Label reads "[NAME] & [NAME]".

## FILLING TIPS (so prompts feel premium & realistic)
- **Person description:** use `06-TRUMP-CHARACTER-BANK.md`. Use "a man/woman
  resembling [name]" + specific era cues (hair colour/style, age, build).
- **Outfit:** name the garment + colour + theme accessories (suit + red tie,
  Army dress uniform + medals, golf polo + cap, tuxedo, wrestling-showman attire).
  Keep outfits in the SAME theme family across panels.
- **Pose:** standing confident, waist-up portrait, action pose (golf swing, fist
  raised). Use the SAME pose family for every panel of one poster.
- **Expression:** confident smile, determined, proud, waving.
- **Scene:** one concrete setting kept consistent across panels (same White House
  / same golf course / same flag studio), varying only small details.
- **Patriotic touches:** American flags, eagles, stars, red-white-blue accents,
  gold trim — but keep them in the header/border, NOT in the top/bottom crop bands.
- **Always keep** the crop-safe block + "AI ART" tag + realism/avoid line.
