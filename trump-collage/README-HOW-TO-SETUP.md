# 🇺🇸 How to Set Up — "Trump Collage-Image Generator" (SEPARATE Project)

> ⚠️ This is a **completely separate, standalone project**. Keep it apart from any
> Trump comparison/poll project. It ONLY makes multi-photo COLLAGE images.

This package turns Claude into a machine that, when you type **ONE theme/idea**,
gives you back:
1. 🎨 a **detailed, crop-safe 4:5 photo-collage prompt** (for ChatGPT / Gemini / etc.),
2. 📝 a **~100-word patriotic Facebook caption**, and
3. #️⃣ **4–6 hashtags**.

A "collage" = ONE subject (or family/group) shown across MULTIPLE photos in a
mosaic/grid — a photo-story. No headlines, no poll, no A/B voting.

## 🛠️ Setup (about 5 minutes)
1. Go to **claude.ai** → **Projects** → **+ Create Project**.
2. Name it: **"Trump Collage-Image Generator"** (keep it separate from any other project).
3. Open it → **Set custom instructions** → paste ALL of
   `COLLAGE-PROJECT-INSTRUCTIONS.md` → **Save**.
4. **Project knowledge / Add content** → upload all **6 files** from `knowledge/`.
5. Done.

## ▶️ How to use it daily (your only job = paste ONE theme)
1. Open the **Trump-Collage-Theme-Bank.xlsx**, pick any row, copy the **"Theme / Idea
   to Paste"** cell.
2. Paste it into the project chat, e.g.:
   - `Trump with the troops`
   - `Trump in the heartland with farmers`
   - `Trump Christmas at the White House`
   - `Trump UFC fight night`
3. Claude replies with a `🎲 Collage:` line + 3 sections:
   - 🎨 IMAGE PROMPT → paste into your image generator.
   - 📝 FACEBOOK CAPTION → ~100 words, ready to post.
   - #️⃣ HASHTAGS → 4–6 tags.
4. Generate the image → crop to 4:5 → post with the caption + hashtags.
5. Mark the row **Done** in the xlsx so you never repeat.

### Want a specific look? Add it after the theme:

If you say nothing, Claude auto-picks a fresh layout/era/mood each time.

## 📐 THE 4:5 SIZE FIX (most important — already built into every prompt)
ChatGPT renders TALLER than 4:5 (≈1003×1568). A 4:5 crop trims the **TOP and BOTTOM**
(~10–12% each). So every collage prompt reserves a **solid-colour EMPTY band on the
top 15% and bottom 15%**, and keeps the **entire collage in the central 70%**.

When you crop:
1. Open the image in any cropper (Canva / Photopea / phone editor).
2. Choose **4:5** (or 1080×1350) and centre the crop vertically.
3. Only the empty top/bottom bands get trimmed → you get a clean **edge-to-edge 4:5
   collage** with nothing cut. ✅

If a band is missing, add to the prompt: "add a solid [colour] empty band across the
top 15% and bottom 15%; keep the whole collage in the central 70%."
