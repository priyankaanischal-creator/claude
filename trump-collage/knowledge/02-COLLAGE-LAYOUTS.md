# 02 — COLLAGE LAYOUTS (Trump Collage Project)

Pick ONE layout per collage (rotate to keep the feed fresh). Each layout sits ONLY
inside the central 70% of the canvas (top 15% + bottom 15% = solid empty bands per
the crop-safe rule). Describe the layout and each cell's position clearly in the
prompt.

---

## LAYOUT 1 — 2-PHOTO VERTICAL STACK
- Two equal photos stacked top + bottom, full width, thin seam.
- **Best for:** a "candid + formal" pair (one natural moment + one posed shot).
- Cells: TOP photo, BOTTOM photo.

## LAYOUT 2 — 3-PHOTO (1 LARGE + 2)
- One large photo (left or top) + two smaller ones.
- **Best for:** a short, punchy story.
- Variants: large-left + 2-stacked-right • large-top + 2-side-by-side-bottom.

## LAYOUT 3 — 2×2 GRID (4 EQUAL)
- Four equal photos in a clean grid, thin seams.
- **Best for:** four balanced moments / "many sides of…".

## LAYOUT 4 — 5-PHOTO MOSAIC (1 LARGE + 4)  ⭐ most popular
- ONE large tall photo on the LEFT (full height of the central zone) + FOUR smaller
  photos stacked on the right and bottom.
- **Best for:** a fuller photo-story (a day, an event, a relationship).
- Cells: LARGE-LEFT, RIGHT-TOP, RIGHT-MIDDLE, BOTTOM-LEFT, BOTTOM-RIGHT.

## LAYOUT 5 — 6-CELL MIXED GRID
- One wide hero photo on top + a mix of medium/small cells below (e.g. a 2×2 plus a
  tall cell), thin seams.
- **Best for:** a richer event or theme with more moments.

## LAYOUT 6 — 7–8 CELL EVENT GRID
- Many cells of mixed sizes, like a social-media event story; one optional text
  overlay on a single cell.
- **Best for:** a whole event (rally, fight night, inauguration, holiday).

## LAYOUT 7 — FILMSTRIP (3–4 STACKED WIDE)
- Three or four wide horizontal photos stacked vertically, thin seams.
- **Best for:** a "timeline / through-the-years" or sequence story.

## LAYOUT 8 — HERO + STRIP
- One big hero photo on top (about 60% of the central zone) + a horizontal strip of
  3 small photos beneath it.
- **Best for:** one signature shot + supporting moments.

---

## SEAM / BORDER OPTIONS (pick 1)
- Thin white seams (clean, modern) • thin dark seams (cinematic/event) • no seams
  (seamless mosaic) • subtle thin gold seams (premium/patriotic).

## SHOT-TYPE PALETTE (mix 3–5 per collage for variety)
- Tight close-up (face/emotion) • waist-up portrait • full-body • candid/unposed •
  wide establishing shot (venue/crowd/landscape) • over-the-shoulder • action moment
  (handshake, salute, swing, fist-raise) • ONE black-and-white photo (classic accent).

## OPTIONAL TEXT OVERLAY (use sparingly, ONE cell max)
- Short, bold, patriotic: "USA! USA! USA!", "We are live 🔥", "GOD BLESS AMERICA",
  "MADE IN THE USA". Keep it INSIDE the central zone, never in the top/bottom bands,
  and never covering the main face.

---

## LAYOUT-TO-THEME QUICK MATCH (suggestions, not rules)
- Single-moment / arrival story → 5-photo mosaic or hero+strip.
- Whole event (rally, UFC, inauguration, holiday) → 6–8 cell event grid (with overlay).
- Family → 2×2 grid or 5-photo mosaic.
- Candid + formal pair → 2-photo stack.
- Through-the-years / timeline → filmstrip.
- "Many sides of Trump" → 2×2 grid or 6-cell mixed.
> Rotate layouts across posts so the same theme can be reused with a fresh look.
