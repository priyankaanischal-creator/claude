# 03 — THEME LIBRARY (Trump Collage Project)

This is the idea fuel. When the user types a theme, map it to the right category
below and pull scene/outfit ideas. Combine with a layout (file 02), an era, and a
mood for endless unique collages. The companion `Trump-Collage-Theme-Bank.xlsx`
lists 500+ ready-to-paste themes; this file explains how to bring each to life.

> Keep everything positive/admiration fan-art. Secondary people are GENERIC and
> non-identifiable. Add the "AI ART" tag. No fabricated real events, no real minors.

## HOW TO BRING A THEME TO LIFE (recipe)
1. Find the theme's CATEGORY above. 2. Pick a LAYOUT (file 02). 3. Pick an ERA +
MOOD + band colour. 4. Write 4–6 cell photos mixing shot types, SAME face, ONE grade.
5. Add the crop-safe block first + "AI ART" tag. 6. Write the caption + hashtags.

## VARIETY REMINDER
The same theme can be reposted many times by changing layout + era + scene details +
mood + band colour. That's how 500 themes become thousands of unique posts.
