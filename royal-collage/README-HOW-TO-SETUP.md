# 👑 How to Set Up — "UK Royal Family Collage-Image Generator" (SEPARATE Project)

> ⚠️ A **completely separate, standalone project**. Keep it apart from your other
> projects. It ONLY makes multi-photo COLLAGE images of the British Royal Family.

Type **ONE search term/idea** → get back:
1. 🎨 a **detailed, crop-safe 4:5 photo-collage prompt** (for ChatGPT / Gemini / etc.),
2. 📝 a **~100-word regal Facebook caption**, and
3. #️⃣ **4–6 hashtags**.

A "collage" = ONE subject (or couple/family/topic) across MULTIPLE photos in a
mosaic/grid. No poll, no headline.

## 🛠️ Setup (about 5 minutes)
1. claude.ai → **Projects** → **+ Create Project**.
2. Name it: **"UK Royal Family Collage Generator"** (separate from other projects).
3. Open it → **Set custom instructions** → paste ALL of
   `COLLAGE-PROJECT-INSTRUCTIONS.md` → **Save**.
4. **Project knowledge / Add content** → upload all **6 files** from `knowledge/`.
5. Done.

---

## ▶️ How to use it daily (your only job = paste ONE term)
1. Open **Royal-Collage-Theme-Bank.xlsx**, pick any row, copy the **"Search Term /
   Idea to Paste"** cell.
2. Paste it into the project, e.g.:
   - `Princess Diana — iconic fashion`
   - `The Crown Jewels`
   - `Queen Elizabeth II through the decades`
   - `Windsor Castle`
   - `William and Kate — love story`
   - `Royal Christmas at Sandringham`
3. Claude returns a `🎲 Collage:` line + 3 sections: 🎨 prompt, 📝 caption, #️⃣ hashtags.
4. Generate the image → crop to 4:5 → post.
5. Mark the row **Done** in the xlsx so you never repeat.

### Want a specific look? Add it after the term:
- `Princess Diana — 2-photo stack, black & white`
- `The Coronation — 8-cell event grid with a "GOD SAVE THE KING" overlay`
- `Queen Victoria — Victorian era, oil-painting style`
If you say nothing, Claude auto-picks a fresh layout/era/mood each time.

## 📐 THE 4:5 SIZE FIX (already built into every prompt)
ChatGPT renders TALLER than 4:5 (≈1003×1568). A 4:5 crop trims the **TOP and BOTTOM**
(~10–12% each). So every prompt reserves a **solid-colour EMPTY band on the top 15%
and bottom 15%** and keeps the **entire collage in the central 70%**.
Crop centred to 4:5 → only the empty bands are trimmed → clean edge-to-edge collage,
nothing cut. ✅

## ✨ Why these look PREMIUM (not plain)
The instructions enforce a **Richness Mandate**: every cell names a detailed setting
(gilded rooms, chandeliers, gardens, cathedrals), detailed wardrobe + jewels (gowns,
tiaras, sashes, uniforms), atmosphere/lighting, and varied shots (incl. one classic
black-and-white). That's what turns a simple collage into a luxury royal photo-story.
