# 02 — COLLAGE LAYOUTS (Royal Collage Project)

Pick ONE layout per collage (rotate for variety). Each layout sits ONLY in the
central 70% of the canvas (top 15% + bottom 15% = solid EMPTY bands per the
crop-safe rule). Describe the layout and each cell's position clearly.

---

## LAYOUT 1 — 2-PHOTO VERTICAL STACK
Two equal photos stacked top + bottom, full width, thin seam.
**Best for:** a portrait + a candid; or a "then & now" pair.

## LAYOUT 2 — 3-PHOTO (1 LARGE + 2)
One large photo + two smaller. **Best for:** a short elegant story.

## LAYOUT 3 — 2×2 GRID (4 EQUAL)
Four equal photos. **Best for:** four balanced moments / a family.

## LAYOUT 4 — 5-PHOTO MOSAIC (1 LARGE + 4)  ⭐ most popular
One large tall photo on the LEFT + four smaller on the right/bottom.
**Best for:** a rich life/era/tribute story.

## LAYOUT 5 — 6-CELL MIXED GRID
One wide hero photo on top + a 2×2 set + one tall cell. **Best for:** events,
tours, or topic stories (jewels, palaces).

## LAYOUT 6 — 7–8 CELL EVENT GRID
Many mixed-size cells like an event story; one optional short text overlay.
**Best for:** Coronation, Royal Wedding, Jubilee, Trooping the Colour.

## LAYOUT 7 — FILMSTRIP (3–4 STACKED WIDE)
Three or four wide horizontal photos stacked, thin seams.
**Best for:** "through the decades" timelines.

## LAYOUT 8 — HERO + STRIP
One big hero photo on top (~60%) + a strip of 3 small photos beneath.
**Best for:** one signature portrait + supporting moments.

---

## SEAM / BORDER OPTIONS (pick 1)
Thin white seams (clean) • thin gold seams (regal/premium) • thin dark seams
(dramatic) • no seams (seamless mosaic) • thin ivory seams (soft elegant).

## SHOT-TYPE PALETTE (mix 3–5 per collage)
Regal full-length portrait • intimate close-up • candid/unposed • wide establishing
(palace/cathedral/crowd) • over-the-shoulder • detail shot (tiara, jewels, hands,
medals) • action/engagement moment (wave, handshake, walkabout) • ONE black-and-white
classic portrait.

## OPTIONAL TEXT OVERLAY (sparingly, ONE cell max — usually for events)
Short, tasteful: "GOD SAVE THE KING", "A ROYAL CELEBRATION", a year ("1981"), or an
event name. Keep it INSIDE the central zone, never in the bands, never over a face.

---

## LAYOUT-TO-THEME QUICK MATCH (suggestions)
- Tribute / life story → 5-photo mosaic or hero+strip.
- Through-the-decades → filmstrip.
- Family → 2×2 grid or 5-photo mosaic.
- Portrait + candid pair → 2-photo stack.
- Big event (Coronation, Wedding, Jubilee) → 6–8 cell event grid (optional overlay).
- Topic/asset (Crown Jewels, palaces, cars, corgis) → 6-cell mixed grid or hero+strip.
> Reuse any theme with a fresh layout + era + wardrobe + mood for a brand-new look.
