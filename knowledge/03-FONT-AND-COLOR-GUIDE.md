# 03 — HEADER, FONT, COLOUR & VOTING GUIDE (Knowledge File)

This file controls the **graphic look**: header styles, colour palettes, fonts,
labels and voting systems. Pick ONE header style + ONE palette + ONE voting
system per poster, and match them to the era/scene.

---

## PART 1 — HEADER STYLES (pick 1; describe it in words in the prompt)
1. **Cream / Parchment + Black Serif** — vintage band, gold scrollwork borders,
   small gold crown on top, bold black classic serif (Playfair-style). Elegant.
2. **Navy Blue Banner + Gold + Crown** — deep navy band, gold double-line border,
   ornate gold crown, white + gold serif (Cinzel/Trajan-style). Premium/luxury.
3. **Black Bar + White/Yellow Condensed** — black band, bold condensed uppercase
   (Anton/Bebas-style), line 1 white, line 2 yellow-gold. High-contrast/modern.
4. **Pink / Magenta + Yellow Condensed** — bright pink band, white + yellow bold
   condensed, thin gold ornament line. Feminine, eye-catching.
5. **Burgundy + Gold Baroque** — burgundy band, heavy gold scrollwork, ornate
   crown, gold + cream old-style serif. Historical/regal.
6. **Minimal Centre-Overlay** — no top band; headline in the centre on a soft
   semi-transparent dark strip, white elegant serif. Candid-photo style.
7. **Sky-Blue Playful** — soft blue band, cute small crown, white + sunny-yellow
   rounded text, tiny star sparkles. Childhood theme.
8. **Emerald / Forest + Gold** — emerald band, gold ornament + crown, white serif.
9. **Black + White Frame (monochrome)** — black band, thin white frame, small
   white crown, white serif. For black-and-white posters.
10. **Mustard / Retro** — faded warm band, groovy 70s serif, brown + burnt-orange.

> Whatever band colour you choose, the **TOP and BOTTOM crop-safe bands should
> use the SAME colour** so a 4:5 crop looks seamless.

## PART 3 — DESCRIBING FONTS (image AIs respond to descriptions, not font names)
Use phrases like:
- "bold black classic serif, elegant and traditional"
- "white + gold ornate serif with a regal feel"
- "bold condensed uppercase sans-serif, modern and high-impact"
- "soft rounded playful font" (childhood)
- "groovy 1970s serif" (retro)
- "elegant thin white serif" (monochrome)
Always add for names: **"large, bold, crystal clear and perfectly readable."**

### Name-colour echo (match each name to its subject for visual unity)
- Match a name's colour to that person's outfit/theme colour where possible
  (e.g. Diana in blue → blue/gold name; Camilla in green → green name).
- In one poster, give each name a **distinct, contrasting** colour so all pop.
- 2 names → one warm + one cool. 3 names → e.g. gold / silver / bronze, or
  blue / green / brown. 4 names → four clearly different label colours.

## PART 4 — NAME LABEL STYLES (pick 1)
1. White rounded box + thin gold border + small gold crown on top.
2. Navy ornamental box + gold scalloped border + crown + 5 gold stars under name.
3. Cream baroque badge + ornate gold frame.
4. Coloured rounded box matching subject (e.g. green box for green outfit).
5. White box + bold name + small subtitle line (title, e.g. "(PRINCESS OF WALES)").
6. Minimal: name only, bold with subtle shadow, no box (candid style).

---

## PART 5 — VOTING / REACTION SYSTEMS (pick 1 per poster; fit it to the theme)
1. **A / B (/ C / D) circle badges** — classic poll letters in coloured circles.
2. **Facebook reactions** — 👍 Like (blue), ❤️ Love (red), 😮 Wow (yellow),
   😆 Haha. Assign one per panel. Great for casual/modern posters.
3. **Ranking medals** — gold "1st", silver "2nd" (+ bronze "3rd") badges in corners.
4. **5-star ratings** — a row of gold stars under each name (premium feel).
5. **Colour-coded names** — each name in its own bold colour (no icons needed).
6. **VS badge** — a gold/silver "VS" coin between two panels/couples.

### Reaction icon rendering note (when using FB reactions)
Render them as clean, instantly recognisable buttons:
- ❤️ Love = red rounded heart • 👍 Like = blue rounded thumbs-up
- 😮 Wow = yellow round face, open mouth • 😆 Haha = yellow laughing face
Place each icon near its panel's name, glowing softly to match the theme.

---

## PART 6 — READABILITY RULES (always apply)
1. Headline sits BELOW the top crop band; labels sit ABOVE the bottom crop band.
2. Names large, bold, with a subtle outline/shadow so they read over any background.
3. Keep names in CAPS or Title Case — never thin or tiny.
4. Don't place any text within ~15% of the very top or very bottom edge.
5. Keep headline clear of the left/right edges too (centre it).
